📊 Pipeline ETL: Análise de Eficiência Financeira
Este projeto foi desenvolvido como parte do desafio de Python para Dados da DIO (Digital Innovation One). O objetivo foi criar um pipeline robusto que extrai dados financeiros, realiza transformações inteligentes e carrega os resultados em um relatório consolidado.

🚀 O Ciclo ETL
O projeto segue as três etapas fundamentais da Engenharia de Dados:

1. Extract (Extração)
Os dados brutos foram extraídos de um arquivo Excel (Controle Financeiro.xlsx), simulando uma fonte de dados operacional.

2. Transform (Transformação)
Utilizando a biblioteca Pandas, realizei as seguintes operações:

Limpeza: Tratamento de dados para garantir a integridade da análise.

Inteligência de Negócio: Cruzamento de dados de sobra financeira e investimentos para gerar indicadores de performance mensal.

3. Load (Carregamento)
A etapa final gera um artefato de saída profissional:

Relatório Excel: Um arquivo .xlsx gerado automaticamente (Relatorio_Financeiro_Final.xlsx).

Visualização: Integração de gráficos comparativos para análise rápida de saúde financeira.

🛠️ Tecnologias Utilizadas
Linguagem: Python 3.x

Bibliotecas: Pandas, Matplotlib, XlsxWriter, Openpyxl.

🔧 Como executar o projeto
Clone o repositório.

Certifique-se de ter as bibliotecas instaladas: pip install pandas matplotlib xlsxwriter openpyxl.

Execute o script: python "Projeto Financeiro ETL DIO.py".
